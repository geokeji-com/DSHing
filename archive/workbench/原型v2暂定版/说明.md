# 上真环境（先做前端）

> 2026-09-21 记。这一节回答「现在这些是样子货，怎么变成真的」。
> 结论：**先做前端**。入库那个 MCP 工具还没写，但不挡前端 —— 前端先按下面的约定写，后端照同一份约定实现，将来一换就通。

## 目标环境

- 跑在**云上那份 DSH** 里，不是我们本机这个。会话、模型、工具链、skill、MCP 都是 DSH 现成的，**我们只做「工作台」这一栏**，其余的不用自己造。
- **每个 user 在云上有一份自己的工作区**（就在那台 DSH 服务器上）。做这个东西就是为了**用户随时随地开个网页**：会话记录、写文章产生的草稿都在自己这份工作区里，换台机器、换个浏览器，打开还是它。
- **知识库、文章库是单独的系统，全走 MCP 调用。** 客户就是知识库 —— 装配台上选客户，实质是选「这次调哪个知识库」。
- **写文章时产物先落在自己的工作区**；**只有确认了，才调工具入库**。
- 入库之后**工作区里那份草稿暂时不删** —— 跟「定期自动清理」一起做。
- 入库那三条规矩（先写远端拿回执、再动工作区 / 删工作区那份失败不算入库失败 / 幂等）见下一节。

## 一条主线的数据流

```
装配台（给谁写 · 用什么料 · 怎么写）
      │ 发送
      ▼
   会话：模型 + skill 写文章  ──►  产物落工作区
      │ 产物落盘（真事件）
      ▼
   机器检查：宿主脚本跑硬规则（不花 token）──► 每篇一份结论
      │
      ▼
   人审（右栏）：忽略此条 ／ 挑几篇发回对话改 ／ 确认入库
      │ 正文一改 ──► 那一篇的旧结论当场作废，退回无色（等你重跑）
      │ 确认 ──► 调 MCP 入库：先写远端拿回执，再动工作区
      ▼
   入库（锁了，只能看）
```

**记一笔：客户 = 知识库。** 装配台上「给谁写」选的那个客户，实质是选「这次调哪个知识库」——
所以客户列表不该我们自己维护，**直接跟着知识库走**（每次要用就找知识库要一份）。
跟着变的两件事：

- **工作区按客户分目录时，目录要用知识库的 id**，显示名从知识库读。不然知识库改了名，工作区就对不上。
- **「新建客户」在真环境里＝去知识库那边建一个**：前端那个 `＋` 只是个入口，建完回来刷新列表，不在本地凭空造一条。

## 前端还差什么（先做这块）

**第一件：把写死的假数据抽成一层读取。** 现在客户、会话、产物、检查结果全是散在代码里的数组和 HTML，先把它们收成几个「读一次」的函数（`读客户` / `读会话` / `读产物` / `读检查结果`），界面一行不动。往后换真数据只动这一层，界面不用再改第二遍。

剩下的，按先后：

1. **发送 → 真会话** —— 现在只往聊天里塞一条假气泡，模型根本没动。
2. **状态机由事件驱动** —— 别再用一个 `chkStage` 变量把整批顶住；每篇自己的状态要能单独走。
3. **「这一轮改了哪几个文件」这个回报** —— 「改完退回无色」全靠它，报不准颜色就乱。
4. **失败态** —— 现在全是顺的，真环境会失败：入库失败、检查失败、模型超时、文件锁了。
5. **篇号 = 文章 id，跨会话稳定** —— 入库幂等、改稿对位都靠它，不能只是列表下标。

## 后端还要做什么（还没写）

1. **入库 MCP 工具** —— 入参、回执、失败原因、幂等键；顺序必须是「先写远端拿回执 → 再动工作区那份草稿」。
2. **硬规则检查脚本** —— 有哪些规则、每条怎么判、知识库怎么读、第几段怎么定位。**这块不用模型**，所以便宜、能反复跑。
3. **工作区目录结构和产物命名** —— 会话记录、草稿、按客户分的目录都在这儿；入库和检查都得靠它找到文件。

## 已定（这一轮聊掉的）

- **一个客户 = 一个文件夹 = 一个知识库**（知识库现在就是一堆文档装在文件夹里）。
- **客户列表不缓存在本地，打开下拉时查一次**（走 MCP）。理由是硬的：每个 user 权限不一样、看到的客户不一样，客户还会新增、会因为服务结束被移除 —— 本地缓存必然过期，而且会把不该看的名字留在本地。
  代价是下拉要等一下，所以两条：
  - 查出来的结果**本次会话内复用**，别每次点开都查；
  - 一次查询把「id + 显示名」**一次拿全**，不要一个客户一次请求。
- **权限由服务端按 user 过滤**：前端不判权限、也拿不到别人客户的名单，只管显示查回来的那些。
- **会话记录存在哪**：存在**这个 user 在云上 DSH 的工作区**里，跟本机这套一个意思。所以换设备、换浏览器，只要还是这个 user，打开网页就是同一份工作区。
- 顺着上一条，**客户下线不影响自己的历史会话** —— 会话存在自己工作区里，不跟着知识库走。工作区里那几篇已经入过库的草稿留着（只读），随时能翻。

## 还没定

- 云上那份 DSH 怎么把这一页挂上去（本机这套是「插件 + 浏览器 UI」，云上大概一样，具体待定）。
- 上真环境测一下「改完自动重跑检查」到底慢不慢 —— **不慢就自动跑一遍**（现在定的是：改完退回无色，重跑可选）。

## 记一笔：「通过」到底做了什么（讨论结论）

**通过 = 宿主直接调 MCP 的入库工具**，不走对话、不花 token。

- 文章写在**自己的工作区**（云上那台 DSH 里、属于这个 user 的那份）；入库 = 调 MCP 写进客户的文章库
- **工作区里那份草稿暂时不删** —— 跟"定期自动清理"一起做（待办）
- 因此在原型上：通过之后**差分还看得到**（正文还在工作区里），只是那篇被锁了

要实现的时候有三条规矩（别丢稿）：

1. **先写远端拿到回执，再动工作区** —— 反了中间一失败就没了
2. **删工作区那份失败不算入库失败**，标成"待清理"下次再删，**绝不回滚远端**
3. **幂等** —— 手抖点两次不能入两篇

界面上「通过」应该是三态，不是瞬间变绿：

```
点通过 → 入库中… → ✓ 已入库     ← 绿底 + 沉底
                 ↘ ✗ 失败 · 重试  ← 留在待审区
```

## 怎么用

- **顶上工具栏的「标注」** —— 橙色虚线框住的就是「要在 DSH 现有界面上加的东西」，
  灰掉的是 DSH 现在本来就有的（示意，不用改）。字母 / 圈号对应草稿上的位置。
- **左栏** —— 分组可以点开点收。鼠标挪到会话上会出现 `⋯`：
  **重命名 / 归档 / 移动至某分组**。
  `＋ 新建任务` 回到装配台；发送后按你选的客户自动归到对应分组。
- **装配台第一行** —— 横着的一张卡：给「谁 · 哪条线 · 第几期」写，三个内联下拉直接点，
  右边 `＋ 新建客户` 就地变输入框，回车就加进下拉并选中。
- **主题** —— 「薄弱问句 / 输入」二选一。
  选**薄弱问句**，下面那块就是能直接勾的表格；**按住往下拖能连着勾一串**；
  表头右边 `⤢` 放大看，`勾差额前 20` 一键勾当前筛选下差额最大的 20 条。
  选**输入**，下面那块直接变成一个大输入框，想写什么就往里打。
- **中间那根拖杆** —— 工作区和「怎么写」在分同一块空间，
  往下拖工作区变高、「怎么写」让位，往上拖反过来。底座始终贴底不动。
- **怎么写** —— 点那条展开，里面是两个标签页：
  **仿写**（贴链接 / 粘正文 / 选文件 + 仿写方式）和 **用 skill**（就是文章类型，多选，
  常用 8 个摆着、`更多` 展开剩下 10 个）。
  两个标签页不互斥，可以同时挂；跟上面的「主题」也正交，都能叠加。
- **右栏四个面板** —— 点标题栏展开，一次只展开一个；右上角 `⟨` 把整栏收起。

## 上一轮（四条）

### 1. 标题行就是「状态 + 预设 + 开始检查」
```
● 未审核   [星辰口腔 · 标准硬检 ▾]   [开始检查]   ▸
```
- 预设**直接就是那个下拉框**，不用展开就知道、也不用展开就能看
- **编辑 / 取消 / 保存 都在展开之后**，出现在规则区最下面那一行（`已勾 12 / 12 条  [编辑]`）
- 编辑的时候「开始检查」会变灰，避免拿没存的规则去跑

### 2. 预设默认锁着，改了要保存
- 锁着的时候：下拉**灰的**、规则**勾不动**、拖高的把手**不出现**
- 点 **编辑** → 下拉能选、规则能勾、把手出来、按钮变成 **[取消] [保存]**
- **取消** → 这次的改动全撤销（回到锁前的样子）
- **保存** → 存下来，锁回去

### 3. 「还没过机器」那块解释删了
没跑的时候正文就是正文，不再弹一句「几条脚本扫一遍几秒钟的事」。

### 4. 检查条跟会话页顶部那条一样高
固定 39px（加边框 40px），跟 `C1 顶部任务条` 的标题行一样。默认收成一条细行。
**只有进入编辑模式，那根拖高的把手才出来** —— 平时不给动。

## 上一轮（右栏三条）

### 1. 右栏里多了两根把手
- **检查条下面那根横的**：往上拖，检查条变矮（规则区跟着缩，内容多就滚）
- **目录和正文中间那根竖的**：往左拖，目录变窄（96 ~ 400px）

加上之前那根（右栏最左边缘拖整栏宽度），现在右栏里三样都能自己调。

### 2. 「开始检查」挪位置了
- **收起时**：标题行写 `● 未审核 · 选择预设`，**右边就是「开始检查」按钮** ——
  预设没改的话，不用展开，直接点
- **展开后**：按钮挪到预设选择旁边（`预设 [星辰口腔·标准硬检 ▾] [存为预设] [开始检查]`），
  因为这时候你多半是在改预设
- 跑完之后标题行变成 `● 已检查 · 12 条规则 · 2 篇有问题`，按钮变「重跑检查」

### 3. 检查结果改成脚本式说法
之前那个「规则 + 位置 + 原文片段」太像 AI 写的报告了。脚本能给的其实就三样：
**哪条规则、命中/没命中什么、在第几段**。现在长这样：

```
机器没过的 2 条
✗ 写作准则 · 提示词暴露
   命中「根据我们给的关键词」   第 1 段
✗ 格式 · 必备结构（导语 / 结论 / FAQ）
   没找到 FAQ 段              全文
其余 10 条通过
```

没跑的时候那块是虚线灰框，写「还没过机器」；全过的时候写「机器检查：12 条全过」。

所以**打了一半的字切模式也不会丢**（跟放大弹窗搬表格是同一套做法）。

### 3. 「怎么写」改成两个标签页：仿写 / 用 skill

原来这行只有「参考文章」一件事。现在是两个大标签页：

| 标签页 | 里面是什么 |
|---|---|
| **仿写** | 大输入框（链接一行一个 / 整篇正文直接粘）+ 选文件 + 仿写方式（一比一 / 模仿结构 / 其他）+ 解析出来的清单 |
| **用 skill** | 一排标签，点着选，可多选；右下角「清空」（这一轮换成了文章类型） |

几条约定：

- **两个标签页不互斥** —— 切标签只切**显示**，两边挂的东西都留着，
  可以「照着 3 篇仿写 + 再过一遍 2 个 skill」。（要是你想改成二选一，很好改）
- **标签上带数字** —— `仿写 3` / `用 skill 2`，收起来也知道哪边有货
- **收起那行的摘要把两边拼起来**，中间用 `｜` 隔开：
  `2 个链接 · 正文 28 字 · 一比一 ｜ 事实核查 等 2 个 skill`
- 蓝色小标签和会话页顶部的任务条也都跟着带上 skill：
  `用 20 条薄弱问句，照着 3 篇参考一比一，过一遍 2 个 skill，给 星辰口腔 写 老榜单`
- 点标签页**不会**顺手把这行折叠掉；收起状态下点标签页，会直接展开到那一页

> 那会儿 skill 是 10 个假的（事实核查 / 医疗广告合规 / …），单独一个 `SKILLS` 数组。
> **这一轮已经删掉了** —— 现在「用 skill」里放的就是文章类型（见上面第 5 条）。

## 上一轮：Landing 页重做

起因两条：中间输入区太挤；「待确认」那张卡一直是占位的，没想好放啥。

### 1. 「待确认」整张卡删掉

薄弱问句改成**就地勾**，那么 **勾着的这些行本身就是待写清单**，不用再点一次

原来那套「开始写 / 发送」两个出口也一并没了，只剩一个发送。

### 2. 三种模式不再互斥，拆成两个维度

|  | 回答的问题 | 性质 |
|---|---|---|
| 薄弱问句 | **写什么**（选题从采集库来） | 和「自己说」互斥 |
| 自己说 | **写什么**（选题我自己说） | 和「薄弱问句」互斥 |
| 参考文章 | **怎么写**（写法照着谁） | 和上面两个正交，**可叠加** |

所以「仿写」不再是一种模式了 —— **挂上参考文章 = 仿写**。
文章类型里那个「仿写」也删了（它跟另外 18 个不是一类东西，混在一起是错的）。
输入框里那个小蓝标签会把两个维度拼成人话，比如
`用 20 条薄弱问句，照着 3 篇参考的结构，给 星辰口腔 写 老榜单`。

### 3. 参考文章：一个大框，链接和正文都往里塞

原来只有一个很窄的单行框，只够放一个 URL。现在是个多行框：

- **一行一个链接** —— 认 `http(s)://` 和 `www.` 开头的行
- **整篇正文直接粘** —— 剩下的行合起来算一篇正文，旁边显示字数
- **选文件** —— 附件（原型里是假的）
- 下面自动列出解析结果，每条都能单独 `×` 掉
- **仿写方式**：一比一 / 模仿结构 / 其他。选「其他」时，
  最底下那个输入框的提示词会换成「说说想怎么仿」—— 这就是你说的"交代怎么仿"的地方

### 4. 薄弱问句就地选，弹窗降级成「放大看」

表格直接摆在装配台上，默认全勾。弹窗不删，但改成纯粹的放大：
表格本体是**同一个 DOM 节点搬过去的**，不是复制一份，所以勾选状态天然同步，
不存在两张表对不上的问题。Esc / 点空白 / 「收起」都能还原。

### 5. 底座钉死，按钮不会跳

装配台是一列 flex，中间工作区 `flex:1`。不管你切到哪个模式、参考框展没展开，
**「写成什么 + 输入框 + 发送」永远在同一个高度**。
切到「自己说」时表格藏起来，那块空间留着不动（放一句提示），所以发送按钮不动。

> 标注模式下，整个装配台现在是一个 **A** 框；原来的 **D**（输入区）没有了。
