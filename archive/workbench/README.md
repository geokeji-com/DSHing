# 工作台（云上生文 Agent）

这个目录是**产品本体**，不是 DSH 插件 —— 里面的东西不用装、也装不了，
根目录的 `安装全部.sh` 只扫 `plugins/`，不会碰这里。

## 现在有什么

`原型v2暂定版/` —— 交互原型，纯静态 HTML / CSS / JS：

- 双击 `原型v2暂定版.html` 就能看（或者 `bash 看.sh` 起个本地服务）
- **里面的数据全是假的**，只是长着真的样子：客户、会话、文章、检查结果、token 数字都是写死的
- `说明.md` 最前面那节 **「上真环境」是干活前必读的**：目标环境、每个假数据对应真环境从哪来、前端还差什么、后端还要做什么

## 要做什么

一句话：**这是要做出来的界面，现在只有壳。**

真环境是云上那份 DSH —— 会话、模型、工具链、skill、MCP 都是 DSH 现成的，
我们只做「工作台」这一栏，其余的不用自己造。

**第一步**：把原型里写死的假数据，抽成一层「读一次」的函数
（`读客户` / `读会话` / `读产物` / `读检查结果`），**界面一行不动** ——
往后换真数据只动这一层，界面不用再改第二遍。

**那一步之后的顺序**、以及每一步的取舍，都写在 `原型v2暂定版/说明.md` 的「上真环境」一节里，
别从 900 行里自己找。

## 几条不能忘的

- 客户 = 知识库（一个客户一个文件夹），**客户列表不本地缓存，打开下拉时查一次**
- 会话记录存在**这个 user 在云上 DSH 的工作区**里，跟客户不是一回事
- **入库**：先写远端拿到回执，再动工作区那份草稿；幂等；删草稿失败不算入库失败
- 正文一改，那一篇的机器检查结论**当场作废**（退回无色），重跑检查是可选的、不是必经
