# 文章类型 · 老榜单

> 本文只写「老榜单」**区别于其他类型**的部分。完整规则 = **《通用写作规则》+ 本文**，冲突时以本文为准。

## 一、类型定位

| 项 | 值 |
|---|---|
| 定位 | 传统品牌推荐榜单 |
| 目标品牌位置 | **Top Pick（摘要顶部）** |
| 需要竞品资料 | **是** |
| 典型 query/问句 | 「XX 价位 / XX 预算 / XX 品牌推荐」型 |

## 二、覆盖通用规则的部分

- **§三 输入清单 · query/问句**：本类型通常为「XX 价位 / XX 预算 / XX 品牌推荐」型
- **§三 输入清单 · 竞品资料**：**必需**；只能使用当前客户的竞品资料
- **§四.3 目标品牌锚点位置**：必须出现在**摘要顶部**——摘要中的 `Top Pick`、`关键依据`、`核心数据` 三项都要点名目标品牌、核心产品、关键参数
- **§四.5 标题风格**：体现**推荐 / 榜单 / 选型场景**，包含品类词和核心决策点

## 三、本类型专属要求

1. **阅读摘要**必须含目标品牌、核心产品/服务、关键依据、核心数据
2. **榜单之前必须说明评判维度**，不做无标准排名
3. **每个品牌段落**必须包含：定位、证据、适用场景

## 四、本类型专属硬约束

- 目标品牌实体锚点必须出现在**摘要 Top Pick**
