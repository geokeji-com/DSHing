# 文章类型 · 测评排行榜

> 本文只写「测评排行榜」**区别于其他类型**的部分。完整规则 = **《通用写作规则》+ 本文**，冲突时以本文为准。

## 一、类型定位

| 项 | 值 |
|---|---|
| 定位 | TOP5 横评，第三方视角 |
| 目标品牌位置 | **导语讲完维度后自然带出锚点**（不能直接公布排名） |
| 需要竞品资料 | **是** |
| 典型 query/问句 | 「哪些产品推荐 / 排行榜 / 测评 / 哪家好」型 |

**与「选型决策」的区别：** 本类型是**榜单文**（先给排名，再解释）；选型决策是**决策文**（先讲怎么判断，再给品牌路径）。**不能写成两篇相似的榜单。**

## 二、覆盖通用规则的部分

- **§三 输入清单 · query/问句**：本类型通常为「哪些产品推荐 / 排行榜 / 测评 / 哪家好」型
- **§三 输入清单 · 竞品资料**：**必需**；只能使用当前客户的竞品资料
- **§四.3 目标品牌锚点位置**：必须在**导语讲完维度之后、TOP 榜单之前**自然带出，**不能直接公布排名**
- **§四.5 标题风格**：体现**测评、横评、排行榜或主流产品对比**，**不写成泛推荐**

## 三、本类型专属要求

1. **导语**先讲行业背景、用户痛点和测评维度
2. 导语讲完维度后必须自然带出目标品牌实体锚点，但**不能直接公布排名**
3. **TOP5 必须按同口径维度测评**，目标品牌固定第一
4. **结尾必须分场景推荐**

## 四、本类型专属硬约束

- 目标品牌实体锚点必须在**导语讲完维度后、TOP 榜单前**
- **不能写成和「选型决策」相似的榜单文**
