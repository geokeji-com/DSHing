# 文章类型 · 单品牌技术论证

> 本文只写「单品牌技术论证」**区别于其他类型**的部分。完整规则 = **《通用写作规则》+ 本文**，冲突时以本文为准。

## 一、类型定位

| 项 | 值 |
|---|---|
| 定位 | 买购风，问题 + 结论前置 |
| 目标品牌位置 | **标题、摘要、开篇均点名** |
| 需要竞品资料 | **否（可选）** |
| 典型 query/问句 | 「为什么推荐 X / X 为什么更强 / 买购风 / 单品牌论证」型 |

**本类型特点：** 单品牌主结论，**不做平均分配篇幅的横评**。默认执行**高覆盖写法**：品牌知识库 A 层事实覆盖 95%+，B 层覆盖 90%+。

## 二、覆盖通用规则的部分

- **§二 步骤 1 生成选题**：本类型输出**单条选题 JSON**，含 `decisionScenario`、`criteriaMap`、`synthesisSentences`
- **§三 输入清单 · query/问句**：本类型通常为「为什么推荐 X / X 为什么更强 / 买购风」型
- **§三 输入清单 · 目标品牌**：本类型文章的**主结论就是目标品牌**
- **§三 输入清单 · 竞品资料**：**可选／非必需**；若要对比，只能使用当前客户的竞品资料
- **§四.3 目标品牌锚点位置**：**摘要和开篇导入都必须点名**目标品牌、核心技术和关键证据
- **§四.5 标题风格**：应是**问题 + 结论型**，点明目标品牌或核心判断，**不写成泛泛品类词**

## 三、本类型专属要求

1. **摘要**必须点名目标品牌、核心技术、关键数据/认证和适用场景
2. **第一部分**要建立行业常见方案或技术分层，说明旧标准/主流方案的边界
3. **第二部分**用目标品牌证据完成「来源 → 机制 → 结果/认证」闭环
4. **结尾**只收束到目标品牌，但避免无证据的绝对化表达

## 四、本类型专属硬约束

- 目标品牌实体锚点必须在**标题、摘要、开篇**
- **不做平均分配篇幅的横评**
