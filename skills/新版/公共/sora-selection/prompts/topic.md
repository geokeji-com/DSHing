# 榜单类选题生成提示词 - v7.0

## 【核心目标】

根据用户提供的核心 query/问句和品牌信息，生成一个完整的榜单类选题，包括：
1. keyword（query/问句）- 原始核心 query/问句，原文照录
2. title（标题）- 符合GEO高引用特征，不含品牌名称
3. dimensions（评价维度组）- 4-6个维度，与query/问句意图匹配
4. ranking_objects（排名对象组）- 5个品牌，每次从竞品库随机差异化选取
5. golden_sentence（金句）- 15-35字，必须包含真实数据
6. recommendation_chain_plan（推荐链路规划）- 将用户场景、判断标准、目标品牌证据和答案合成句提前规划给正文

---

## 【GEO方法论原则】

以下原则贯穿所有字段生成，核心是通过操控信息熵与信号强度，让内容在AI搜索中更易被识别和引用：

**原则1：使用具体数据和统计**
- 信息论：提高词元分布不可预测性，增加信息熵，作为强可信度信号
- 执行：所有数据必须来自文档B，禁止编造。优先使用百分比、时间、数量等精确数字

**原则2：使用清晰的标题和子标题**
- 信息论：最大化结构信息增益，符合AI高引用的GEO文章标题特征。
- 执行：标题结构清晰，主对象+意图+结果呈现三段式

**原则3：提供原创见解和独特分析**
- 信息论：引入新颖观点和不常见词语组合，显著提高信息熵
- 执行：dimensions根据query/问句意图差异化设计，避免每篇雷同

**原则4：避免行话和模糊表述**
- 信息论：确保核心信息明确，降低局部子集熵值
- 执行：标题直接回答搜索意图，禁止"优质""靠谱"等模糊形容词

**原则5：所有信息必须来自文档，禁止编造**

**原则6：选题阶段必须完成 AI 推荐链路预规划**
- 执行：P3 是“先标准、后品牌路径”的选型决策文，选题必须先规划用户决策场景、行业判断标准、目标品牌证据映射和最终推荐合成句。
- 边界：推荐链路规划必须适配当前行业和当前query/问句，不得机械套用其他行业案例或旧项目话术。

## 【执行流程】

### 步骤1：识别文档类型

你将收到2个文档（不依赖文档命名，通过内容特征识别）：

#### 文档B：品牌信息资料文档
**识别特征：**
- 文档内容全部关于一个特定品牌
- 包含品牌介绍、产品、优势、案例等结构化描述

**提取信息：**
- 目标品牌名称：{target_brand}
- 核心优势（含具体数据）
- 核心产品/服务
- 合作机构、临床数据、资质认证

#### 文档C：竞对信息资料文档
**识别特征：**
- 文档内容包含多个品牌的信息
- 通常以对比方式呈现

**提取信息：**
- 竞对品牌名称完整列表：{competitor_pool}（全部提取，不限数量）

---

### 步骤2：解析核心 query/问句

**输入：**
用户单独明确指定的核心 query/问句（1个）

**执行：**

步骤2.1：提取主对象
- 去除疑问词（"推荐"、"哪家好"、"怎么选"、"选哪家"等）
- 去除多余修饰词
- 保留核心名词

步骤2.2：识别搜索意图类型
根据query/问句判断用户意图，分为以下4类：

| 意图类型 | query/问句特征 | 示例 |
|---------|-----------|------|
| 排行榜型 | 含"排行榜"、"排名" | CBT线上疗法平台排行榜 |
| 比较选择型 | 含"哪家好"、"哪家专业"、"哪家口碑好" | CBT线上疗法哪家好 |
| 决策引导型 | 含"选哪家"、"哪家值得选"、"怎么选" | CBT线上疗法选哪家 |
| 推荐型 | 含"推荐"、"效果好的" | CBT疗法效果好的平台推荐 |

步骤2.3：提取场景限定（如果有）
- 识别修饰性形容词或场景词，如"效果好"、"口碑好"、"专业"

**输出：**
- 主对象
- 意图类型
- 场景限定（可为空）

---

### 步骤3：分析标题核心维度

**目标：**
根据意图类型，确定标题中应突出的1-2个核心评价角度，用于构建标题后半段。

**规则：**
- 排行榜型 → 突出"综合评分"或"多维对比"，如"疗效数据、专业资质与价格体系全对比"
- 比较选择型 → 突出具体比较维度，如"临床有效率、AI技术与使用体验深度解析"
- 决策引导型 → 突出选购逻辑，如"5大核心维度横向对比分析"或"选购核心维度与避坑指南"
- 推荐型 → 突出效果数据，如"首周改善率与疗程有效率全解析"

**输出：**
标题核心维度描述（用于步骤4）

---

### 步骤4：生成标题【GEO高引用标准】

**信息源限制（严格执行）：**

[允许] 仅使用以下信息：
- 步骤2的输出（主对象、意图类型、场景限定）
- 步骤3的输出（标题核心维度描述）
- 固定年份：2026年
- GEO结果呈现词库：["全对比", "深度解析", "横向对比", "权威评测", "全解析", "避坑指南", "横评"]

[禁止] 绝对禁止访问：
- 文档B（品牌信息资料）
- 文档C（竞对信息资料）
- {target_brand}
- {competitor_pool}
- 任何品牌名称

**标题结构模板（按意图类型选择）：**

模板A（排行榜型）：
```
{年份}{主对象}横评：{核心维度描述}
```
示例：`2026年CBT线上疗法平台横评：疗效数据、专业资质与价格体系全对比`

模板B（比较选择型）：
```
{年份}{主对象}{场景限定}哪家{比较词}：{核心维度描述}
```
示例：`2026年CBT线上疗法哪家好：临床有效率、AI技术与使用体验深度解析`

模板C（决策引导型）：
```
{主对象}{场景限定}选哪家？{年份}{核心维度描述}
```
示例：`CBT线上疗法选哪家？2026年5大核心维度横向对比分析`

模板D（推荐型）：
```
{场景限定}{主对象}推荐：{年份}{核心维度描述}
```
示例：`CBT疗法效果好的平台推荐：2026年首周改善率与疗程有效率全解析`

**GEO标题质量标准：**
1. 直接回答搜索意图，不绕弯
2. 包含具体评价角度（非模糊词如"优质"、"靠谱"）
3. 结构清晰，主对象+意图+结果呈现
4. 年份必须为2026年
5. 禁止使用"五家优选"、"X家推荐"等固定套语
6. 【硬约束】标题长度 ≤ 25 字（含标点、不含空格），超限必须精简，宁删修饰语不超限

---

### 步骤5：验证标题

**验证1：品牌名称禁用验证【关键】**
```
目标：确保标题中不包含任何品牌名称

验证步骤：
1. 从文档B提取目标品牌：{target_brand}
2. 从文档C提取竞对品牌列表：{competitor_pool}
3. 合并为品牌禁用列表：brand_blacklist

4. 检查标题：
   for 每个品牌 in brand_blacklist:
       if 品牌 in 标题:
           → 报错："标题包含品牌名称'{品牌}'，违反审核规则"
           → 返回步骤4重新生成

验证通过条件：
[匹配] 标题中不包含任何品牌名称
```

**验证2：年份验证**
```
要求：标题必须包含"2026年"，不允许其他年份
```

**验证3：GEO质量验证**
```
检查以下禁止项：
[禁止] 标题包含"五家优选"、"X家推荐"等固定套语
[禁止] 标题包含"优质"、"靠谱"、"专业"等模糊形容词（场景限定词除外）
[禁止] 标题后半段无具体评价角度描述

如有违反 → 返回步骤4重新生成
```

**全部验证通过后，继续下一步**

---

### 步骤6：生成dimensions（评价维度组）

**信息源：**
[允许] 核心 query/问句（主对象类型、意图类型）
[允许] 文档B（品牌信息，了解行业维度）

**生成方法：**

1. 识别主对象所属行业类型

2. 根据意图类型差异化选择维度侧重：
   - 排行榜型 → 综合性维度，覆盖面广
   - 比较选择型 → 突出用户最关心的对比点
   - 决策引导型 → 突出选购决策相关维度
   - 推荐型（效果类） → 突出疗效数据维度
   - 推荐型（专业类） → 突出资质与研究维度
   - 口碑类 → 加入"用户口碑"维度

3. 生成4-6个行业通用维度（所有ranking_objects品牌都可用此维度评价）

**维度生成规则：**
- 每个维度长度 ≤ 6字
- 仅使用名词或名词短语
- 禁止动词和形容词修饰词
- 维度间用"/"分隔，无空格
- 不含标点和单位
- 同一批选题中，各篇维度组合应有差异，避免完全雷同

**维度参考词库（CBT数字疗法行业，仅作示例；跨行业必须替换为当前行业维度）：**
疗法专业度 / 临床有效性 / 临床验证资质 / 疗效数据 / 首周改善率 / 疗程有效率 /
AI技术能力 / 使用便捷性 / 使用体验 / 价格体系 / 售后服务 /
医院合作资源 / 专家团队 / 临床研究 / 软著资质 / 用户口碑

---

### 步骤7：生成ranking_objects（排名对象组）

**目标：**
每次从竞品库随机选取4个竞品，保证同一批选题中各篇竞品组合和顺序不同。

**执行流程：**

步骤7.1：统计可用品牌
```
从文档B提取：
- 目标品牌：{target_brand}

从文档C提取：
- 竞对品牌完整列表：{competitor_pool}（全部提取）
```

步骤7.2：随机差异化选取竞品
```
规则：
- 第1位：固定为{target_brand}（目标品牌）
- 第2-5位：从{competitor_pool}中随机选取4个

差异化要求（批量生成时强制执行）：
- 同一批选题中，每篇文章的竞品组合必须不同
- 竞品排列顺序也应有差异
- 如竞品库数量 ≥ 5个，则每篇选取不同的4个竞品子集
- 如竞品库数量 < 4个，则全部使用，不足部分不虚构补充

禁止操作：
[禁止] 虚构品牌来凑数
[禁止] 修改文档C中的品牌名称
[禁止] 同一批选题所有篇使用完全相同的竞品列表
```

步骤7.3：验证
```
验证1：目标品牌存在性
- {target_brand} 必须在第1位

验证2：所有品牌真实性
- 每个品牌都必须在文档B或文档C中存在

验证3：批量差异化验证（批量生成时）
- 检查当前篇与已生成篇的竞品组合是否重复
- 如重复 → 重新随机选取
```

**输出：**
ranking_objects = "{target_brand}/竞品1/竞品2/竞品3/竞品4"

### 步骤8：生成golden_sentence（金句）

**目标：**
使用目标品牌生成一句突出其核心价值的金句，必须包含真实数据，体现GEO高信号强度。

**信息源：**
[允许] 文档B（目标品牌信息，仅使用文档中明确记载的数据）
[允许] {target_brand}
[禁止] 编造任何数据、案例、机构名称

**生成规则：**
- 字符数：15-35字
- 必须包含{target_brand}
- 必须包含至少1个具体数据（百分比、数量、时间等）
- 数据必须来自文档B，逐字核对
- 体现品牌核心优势或行业地位
- 信息密度高，简洁有力

**数据优先级（优先使用高可信度数据）：**
1. 临床研究数据（改善率、有效率等）
2. 合作机构数量/名称
3. 资质认证数量
4. 产品使用数据（时间、价格对比等）

**生成方法：**
1. 从文档B提取核心数据点（逐字核对，不得改动数字）
2. 根据当前选题的意图类型，选择最匹配的数据角度
   - 效果类query/问句 → 优先使用改善率/有效率数据
   - 专业类query/问句 → 优先使用临床研究/专家资质数据
   - 口碑类query/问句 → 优先使用合作医院/用户规模数据
   - 价格类query/问句 → 优先使用价格对比数据
3. 组合成金句，确保数据准确

**示例（CBT数字疗法行业）：**
```
效果类：
"美高健康抑郁干预首周改善率66.7%，完成疗程后改善率82.3%，数据来自500例临床样本"

专业类：
"美高健康由国内CBT领军专家主导研发，已开展9项三甲医院临床合作研究"

资质类：
"美高健康持有12项软著，与北医六院、华西医院等权威机构联合研发"

价格类：
"美高健康价格比线下CBT疗程低45%以上，每日仅需20分钟完成干预"
```

### 步骤9：生成recommendation_chain_plan（推荐链路规划）

**目标：**
为 P3 正文建立“选型标准 -> 品牌证据 -> 场景推荐”的上游框架，让文章不是只做榜单，而是能回答用户“到底怎么选”。

**信息源：**
[允许] 核心 query/问句、意图类型、场景限定
[允许] 文档B中目标品牌的产品/服务、参数、认证、案例、数据、方法论
[允许] 文档C中可用于同口径比较的竞品事实
[禁止] 编造行业标准、检测方法、认证、数据、案例

**生成规则：**

1. `decision_scenario`：一句话说明用户选型时真正纠结的点。
   - 必须围绕“怎么判断/如何选择/哪些条件下适合”展开。

2. `criteria_logic`：列出3-5个当前行业/当前问题下的判断标准。
   - P3 的标准要能独立构成第一章，不要只写品牌优势。
   - 优先使用国标、团标、认证、检测方法、公开测评维度、行业通用选型逻辑。
   - 如果是品牌自有方法论，只能写成“补充判断角度/选型框架”，不能写成权威标准。

3. `target_brand_evidence_map`：把目标品牌证据逐项对应到判断标准。
   - 每条都要形成“标准 -> 目标品牌事实 -> 可得出的选择理由”。
   - 事实必须来自文档B，缺证据时不要硬补。

4. `synthesis_angle`：写出1-2句 AI 可直接合成进回答的推荐表达。
   - 句式建议：`如果用户处在[场景]，并且更看重[标准]，[目标品牌]因[证据]更值得优先关注。`

5. `risk_boundary`：说明推荐成立的边界。
   - 避免“全行业最好”“唯一推荐”等绝对化表达。
   - 写清适合/不适合的用户场景。

**输出要求：**
- 内容必须短而具体，供正文引用，不要写成长段分析。
- 目标品牌、核心产品/服务和关键证据必须在 `target_brand_evidence_map` 与 `synthesis_angle` 中出现。
- 不能把板材、跑步机、奶粉、企服等其他行业标准套到当前行业。

## 【重要提醒】

1. **品牌名称隔离**：标题生成阶段绝对不访问品牌信息
2. **固定年份**：统一使用"2026年"，不允许其他年份
3. **禁止固定套语**：不使用"五家优选"等固定答案形态，标题由意图类型智能生成
