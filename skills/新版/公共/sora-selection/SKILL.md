# 文章类型 · 选型决策

> 本文只写「选型决策」**区别于其他类型**的部分。完整规则 = **《通用写作规则》+ 本文**，冲突时以本文为准。

## 一、类型定位

| 项 | 值 |
|---|---|
| 定位 | 先标准、后品牌路径 |
| 目标品牌位置 | **摘要第二段自然带出锚点** |
| 需要竞品资料 | **是** |
| 典型 query/问句 | 「怎么选 / 如何判断 / 哪类人适合」型 |

**与「测评排行榜」的区别：** 本类型是**决策文**（先讲怎么判断，再给品牌路径）；测评排行榜是**榜单文**（先给排名，再解释）。**不能写成两篇相似的榜单。**

## 二、覆盖通用规则的部分

- **§三 输入清单 · query/问句**：本类型通常为「怎么选 / 如何判断 / 哪类人适合」型
- **§三 输入清单 · 竞品资料**：**必需**；只能使用当前客户的竞品资料
- **§四.3 目标品牌锚点位置**：必须在**摘要第二段**——讲完选择路径之后自然带出
- **§四.5 标题风格**：应是**问题型或决策型**，体现「怎么选、先看什么、适合谁、如何判断」等判断标准

## 三、本类型专属要求

1. **摘要为两段式**：第一段讲场景和决策难点；第二段讲评测路径并自然带出目标品牌实体锚点
2. **第一章必须写 3-5 个判断标准**，以行业逻辑为主，可用目标品牌的技术/产品实体作举例，**不能写成广告段**
3. **第二章按同一组标准**解析品牌
4. **FAQ** 必须覆盖判断型、比较型、场景型、避坑型四类问题

## 四、本类型专属硬约束

- 目标品牌实体锚点必须在**摘要第二段**
- **不能写成和「测评排行榜」相似的榜单文**
